🔌 API Endpoints

🔐 Auth
POST /api/auth/register
POST /api/auth/login
POST /api/auth/logout
GET /api/auth/me
📍 Destinations
GET /api/destinations
GET /api/destinations/{slug}/hotels
🏨 Hotels
GET /api/hotels ?destination=&check_in=&check_out=&guests=&star=&price_min=&price_max=&sort=&page=
GET /api/hotels/{slug}
GET /api/hotels/{slug}/rooms ?check_in=&check_out=
GET /api/hotels/featured
📋 Bookings (require auth)
GET /api/bookings
POST /api/bookings
GET /api/bookings/{booking_code}
DEL /api/bookings/{booking_code} (cancel)
💳 Payments (require auth)
POST /api/payments/create → redirect to VNPay/MoMo
GET /api/payments/vnpay/callback
GET /api/payments/momo/callback
GET /api/payments/{id}
